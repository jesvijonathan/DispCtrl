// Display enumeration only. The engine has its own list for window and taskbar
// manipulation; keeping them separate stops the app pulling in APIs it has no
// business calling.

// ---- monitor enumeration (GDI view) ----
EnumDisplayMonitors
GetMonitorInfo
MONITORINFOEXW
MonitorFromPoint
EnumDisplaySettingsEx
EnumDisplayDevices
DISPLAY_DEVICEW
DEVMODEW
ENUM_DISPLAY_SETTINGS_MODE

// ---- Connecting & Configuring Displays (CCD) ----
// The only API that ties an HMONITOR to a stable, replug-surviving identity.
GetDisplayConfigBufferSizes
QueryDisplayConfig
DisplayConfigGetDeviceInfo
DISPLAYCONFIG_PATH_INFO
DISPLAYCONFIG_MODE_INFO
DISPLAYCONFIG_TARGET_DEVICE_NAME
DISPLAYCONFIG_SOURCE_DEVICE_NAME
DISPLAYCONFIG_DEVICE_INFO_TYPE
DISPLAYCONFIG_VIDEO_OUTPUT_TECHNOLOGY
QUERY_DISPLAY_CONFIG_FLAGS

// ---- DPI ----
GetDpiForMonitor
MONITOR_DPI_TYPE

// ---- night light (per-display gamma ramps) ----
// Windows exposes no API for its own night light, so warmth is applied the way
// every third-party tool does it: by rewriting the display's gamma ramp. It is
// per-device, immediate, and undone by restoring the ramp that was there.
CreateDC
DeleteDC
SetDeviceGammaRamp
GetDeviceGammaRamp

// ---- dark mode ----
// Writing the registry value changes the setting; it does not tell anything
// already running that it changed. Windows' own Settings page broadcasts, and
// without doing the same an app keeps its old colours until it restarts.
SendMessageTimeout
SEND_MESSAGE_TIMEOUT_FLAGS
WM_SETTINGCHANGE

// ---- error codes ----
WIN32_ERROR
