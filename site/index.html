Features

Everything about your displays,
in one place

Built for desks with more than one screen, and for the laptops that Windows never quite gets right.

Unison brightness

One slider moves every display together, each inside a range you calibrate once, so a laptop panel and an external monitor match at every level. Hardware brightness over DDC/CI and through Windows, with software dimming below the panel's floor. Windows' own Quick Settings slider and your laptop's brightness keys can drive them all.

Keep awake & stay active

Stop the PC sleeping indefinitely, for a set time or until an hour, without touching your power plan.

Stay active keeps the screen on and stops the lock screen, and chat apps like Teams, marking you Away. It nudges the pointer by one pixel, and only after a minute idle.

External monitors can power down on their own after inactivity, and come back when you return.

Night light, per display

Warmer and dimmer than Windows allows, down to 1900K: per monitor or in unison, scheduled or following Windows.

Taskbar, where you want it

Hide it on some displays and keep it on others, with a native slide. Optional glass blur, tint and transparency.

Your monitor's own controls

Contrast, input source, picture mode, colour preset, volume and more, over DDC/CI. It only ever offers values the monitor itself accepts, and a shared device library names the codes manufacturers leave undocumented.

OLED care & focus

Two-stage idle dimming for OLED panels that pauses for full-screen video and games, plus an instant screen rest. Focus mode dims everything around the window you're using.

Global hotkeys

Brightness, night light, focus, keep awake and more, even with the window closed. It warns you when another program already owns a shortcut.

CtrlAltPgUpPgDnND

Display setup, done properly

Resolution, refresh rate, scaling, HDR and orientation per monitor, per-monitor wallpaper, and an arrangement you drag by each display's real physical size.

Quick panel

One click from the taskbar

Click the tray icon and the panel rises from the taskbar, like Windows' own Quick Settings, and sinks back when you click away.

  • One slider for every display, and a row for each one
  • Tiles for night light, dark mode, focus, keep awake, stay active, the taskbar and OLED care
  • Options behind every tile's arrow, so nothing needs digging for
  • Yours to arrange: choose which sections, tiles and rows appear
Tour

Built like Windows 11 itself

WinUI 3 with Mica and Fluent controls. It feels like part of Windows because it's built from the same parts.

Command line

Every feature,
scriptable

dispctrl does everything the app does, with JSON output and meaningful exit codes. Use it in scripts, Task Scheduler and your own shortcuts.

  • Per display or all at once: brightness, night light, modes, inputs
  • Monitor controls by name, including ones the device library maps
  • Talks to the running engine, or works on its own

        Privacy policy
        

          
DispCtrl collects no personal data. It has no accounts, no analytics, no telemetry and no advertising, and it makes no network requests of its own.

          
What stays on your PC

          
Settings, presets, logs and the list of monitors you have used live in %LOCALAPPDATA%\DispCtrl and never leave your computer. Uninstalling offers to delete them.

          
When you choose to share

          
"Report a problem" and "Share a monitor" open a prefilled GitHub issue in your own browser. Serial numbers, device paths, file paths and your account name are removed first, and you can read the whole text before sending. Nothing is sent unless you press Submit on GitHub, and what you then publish is covered by GitHub's privacy statement.

          
This website

          
Hosted on GitHub Pages. It sets no cookies and uses no analytics. It asks GitHub's public API for the star count and draws the donation QR code in your browser.

Your hardware

          
DispCtrl changes real hardware settings: monitor controls over DDC/CI, display modes, gamma and power. It only offers values a monitor reports it accepts, and never writes an undocumented code unless a reviewed definition marks it safe. Even so, monitors differ, and you use it at your own risk. A monitor's own menu, or DispCtrl's per-display reset, puts things back.
